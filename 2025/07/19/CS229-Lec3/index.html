Newton’s method enjoys a property called Quadratic Convergence, which means if in a certain iteration we have an error of 0.01, then in the next iteration the error will become around 0.0001, and in the third iteration the error will be around 0.00000001 and so on.

Typically, Newton’s method enjoys faster convergence than (batch) gradient descent, and requires fewer iterations to get very close to the minimum. However, one iteration of Newton’s can be more expensive than one iteration of gradient descent, since it requires finding and inverting an n + 1-by-n + 1 Hessian. Thus if the number of parameters is not to large, it is usually much faster overall.

When Newton’s method is applied to maximize the logistic regression log likelihood function ℓ(θ), the resulting method is also called Fisher scoring.
