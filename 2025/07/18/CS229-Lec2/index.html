Linear Regression

Example and Terminology

  • Training Set → Learning Algorithm → h (hypothesis)
  • input → h → estimated value

How to represent h?

  • $h(x)=\sum_{j=0}^{n}\theta_jx_j$ where x0 = 1
  • θ=“parameters”
  • m= # training examples
  • n= # features
  • 𝓍= “inputs/features”
  • 𝓎= “output/target”
  • (x, y)= training example
  • (x(i), y(i))= i-th training example
  • ‘#’= number sign

hθ(x) = h(x)

What we are doing is to choose θ s.t. h(x) ≈ y for training data, i.e. $$ \text{minimize }\dfrac{1}{2}\sum_{i=1}^{m}\left(h_{\theta}\left(x^{(i)}\right)-y^{(i)}\right) $$

Here we use squared error rather than absolute error or errors to the power of 4. As for the reasons, we will discuss about it later.

Gradient descent

Start with some values of θ (say $\theta=\vec{0}$), and keep changing θ to reduce J(θ).

One step of gradient descent can be implemented as follows:

$$ \theta_j:=\theta_j - \alpha \dfrac{\partial}{\partial \theta_j} J(\theta) $$

where α stands for the learning rate and := stands for assignments, assigning the value on the right to the variable on the left. For example, a := a + 1 means incrementing the value of a by 1. And things like “a = b” represent facts.

$$ \dfrac{\partial}{\partial \theta_j}J(\theta)=(h_{\theta}(x)-y)x_j $$

Mathematical deriviation of this equation can be found in cs229-notes1.pdf, which is trivial. Plugging this result back to the formula, one step of the gradient descent is:

θj := θj + α(y(i) − hθ(x(i)))xj(i)

Since we have m training examples, we have:

$$ \theta_j:=\theta_j+\alpha\sum_{i=1}^{m}\left(y^{(i)}-h_{\theta(x^{(i)})}\right)x_j^{(i)} $$

and the LMS(least mean squares) algorithm can be shown as

$$ \begin{align}\text{rep}&\text{eat until convergence:}\nonumber\\ &\text{ }\theta_j:=\theta_j+\alpha\sum_{i=1}^{m}\left(y^{(i)}-h_{\theta(x^{(i)})}\right)x_j^{(i)} \text{ (for every )}j.\nonumber\end{align} $$

“Note that while gradient descent can be susceptible to local minima in general, the optimization problem we have posed here for linear regression has only one global, and no ohter local, optima; thus gradient descent always converges (assuming the learning rate α is not too large) to the global minimum. Indeed, J is a concex quadratic function.”

The convexity of the function J(θ) can be verfied by computing its Hessain matrix. The Hessian matrix is H = xTx, where x is the input vector. For any non-zero vector z, we have zTHz = (xTz)T(xTz) which is always non-negative, which shows that H is positive semi-definite.

However, convexity is a rare property for functions. In practical applications, the loss function is a high-dimensional function. In high-dimensional spaces, the stationary points of a randomly selected function are almost always saddle points, which do not prevent continued gradient descent. Moreover, if you believe that deep learning can extract meaningful patterns, the distance between local optima and the global optimum should not be excessively large.

The gradient descent shown above is batch gradient descent, where we think for all the training data and calculate the sum. This can be quite time-and-resouces-consuming. We need an alternative algorithm. That is stochastic gradient descent, where we update the parameters according to the gradient of error with respect to that single training example only. Although stochastic gradient descent may oscillate around the minumum of J(θ), in practice the result will be reasonably good approximations to the true minumum (simply by reducing the learning rate over time) and is oftern preferred over batch gradient descent particularly when the training set is large.

The noraml equation

  • works only for linear regression

Target

set $\nabla_{\theta}J(\theta)=\vec{0}$ and we will get the global minimum (since its a convex function).

Matrix Derivative

For a mapping f : ℝn × m → ℝ, the derivative of f with regard to a matrix An × m is defined as

$$\dfrac{\partial}{\partial A}f(A)=\begin{bmatrix}\frac{\partial f}{\partial A_{1,1}} & \frac{\partial f}{\partial A_{1,2}} & \dots & \frac{\partial f}{\partial A_{1,m}} \\ \frac{\partial f}{\partial A_{2,1}} & \frac{\partial f}{\partial A_{2,2}} & \dots & \frac{\partial f}{\partial A_{2,m}} \\ \vdots & \vdots & \ddots & \vdots \\\frac{\partial f}{\partial A_{n,1}} & \frac{\partial f}{\partial A_{n,2}} & \dots & \frac{\partial f}{\partial A_{n,m}}\end{bmatrix}$$

Matrix derivative obeys the chain rule, which can be proved by simply expand out the definition of these matrices.

Trace

trA= sum of diagonal entries  = ∑Ai, i

“trace of A”

useful properties for trace function:

  • trA = trAT transpose
  • ∇ATf(A) = (∇Af(A))T
  • f(A) = trAB ⇒ ∇Af(A) = BT
  • trAB = trBA
  • trABC = trCAB (cyclic permutation property)
  • ∇AtrAATC = CA + CTA
    • To simply understand it, just regard it as the matrix version of $\dfrac{\text{d}}{\text{d}a}a^2c=2ac$.

As for the proof for the former five properties, just expand out the definition of these matrices. Here we prove the fifth property：

Firstly, we know that

$$(AA^T)_{i,j}=\sum_{l=1}^{n}A_{i,l}A_{l,j}$$

so we know that an entry for the product of the 3 matrices can be shown as

$$\begin{align}(AA^TC)_{i,j}&=\sum_{k=1}^{n}(AA^{T})_{i,k}C_{k,j}\nonumber\\&=\sum_{k=1}^{i}C_{k,j}\sum_{l=1}^{n}A_{i,l}A_{l,k}\nonumber.\end{align}$$

Thus trAATC is given by

$$\begin{align}\text{tr}AA^TC&=\sum_{i=1}^{n}(AA^TC)_{i,i}\nonumber\\&=\sum_{i=1}^{n}\sum_{k=1}^{n}C_{k,i}\sum_{l=1}^{n}A_{i,l}A_{l,k}\nonumber\end{align}$$

To get the derivative of trAATC, we extract the terms related to Ai, j,

$$\begin{align}A_{i,j}\left(\sum_{k=1}^{n}A_{k,j}C_{k,i}+\sum_{1\leq k\leq n \land k \neq i}A_{k,j}C_{i,k}\right)&=A_{i,j}\left(\sum_{1\leq k \leq n \land k \neq i}(A_{k,j}C_{k,i} + A_{k,j}C_{i,k})\right) + A_{i,j}^2C_{i,i}\nonumber\end{align}$$

So the derivative of trAATC with regard to the entry Ai, j is

$$\begin{align}\dfrac{\partial}{\partial A_{i,j}}\text{tr}AA^TC&=\sum_{1\leq k\leq n\land k\neq i}(A_{k,j}C_{k,i} + A_{k,j}C_{i,k})+2A_{i,j}C_{i,i}\nonumber\\&=\sum_{k=1}^{n}C_{k,i}A_{k,j} + \sum_{k=1}^{n}C_{i,k}A_{k,j}\nonumber\\&=(C^{T}A)_{i,j}+(CA)_{i,j}\nonumber\end{align}$$

And we come to our conclusion that $$\dfrac{\partial}{\partial A}\text{tr}AA^TC=CA+C^TA$$

Mathematical derivation of the normal equation

Based on the properties, we have

$$J(\theta)=\dfrac{1}{2}\sum_{i=1}^{m}\left(h\left(x^{(i)} - y^{(i)}\right)\right)^2$$

Arranging the inputs properly, we get

$$X\theta=\begin{bmatrix}\left(x^{(1)}\right)^T\\\left(x^{(2)}\right)^T\\\dots\\\left(x^{(m)}\right)^T\end{bmatrix}\begin{bmatrix}\theta_1\\\theta_2\\\dots\\\theta_n\end{bmatrix}=\begin{bmatrix}\left(x^{(1)}\theta\right)^T\\\left(x^{(2)}\theta\right)^T\\\dots\\\left(x^{(m)}\theta\right)^T\end{bmatrix}=\begin{bmatrix}h\left(x^{(1)}\right)\\h\left(x^{(2)}\right)\\\dots\\h\left(x^{(m)}\right)\end{bmatrix}$$

Define y⃗ by

$$\vec{y}=\begin{bmatrix}y^{(1)}\\y^{(2)}\\\dots\\y^{(m)}\end{bmatrix}$$

$$X\theta-y=\begin{bmatrix}h\left(x^{(1)}\right)-y^{(1)}\\h\left(x^{(2)}\right)-y^{(2)}\\\dots\\h\left(x^{(m)}\right)-y^{(m)}\end{bmatrix}$$

Thus we rewrite J(θ) as

$$J(\theta)=\dfrac{1}{2}(X\theta-y)^T(X\theta-y)$$

Calculating its derivative, we have

$$\begin{align}\nabla_{\theta}J(\theta)&=\nabla_{\theta}\dfrac{1}{2}(X\theta-y)^T(X\theta-y)\nonumber\\&=\dfrac{1}{2}\nabla_{\theta}(\theta^TX^T-y^T)(X\theta-y)\nonumber\\&=\dfrac{1}{2}\nabla_{\theta}\left(\theta^TX^TX\theta-\theta^TX^Ty-y^TX\theta+y^Ty\right)\nonumber\end{align}$$

Notice that J(θ) is a real number, and the trace of a real number is simply itself, so we have

$$\begin{align}\nabla_{\theta}J(\theta)&=\dfrac{1}{2}\nabla_{\theta}\text{tr}\left(\theta^TX^TX\theta-\theta^TX^Ty-y^TX\theta+y^Ty\right)\nonumber\\&=\dfrac{1}{2}\left(X^TX\theta+X^TX\theta-X^Ty-X^Ty\right)\nonumber\\&=X^TX\theta-X^Ty\nonumber\end{align}$$

The second equation derives from the following three properties,

  • $$\begin{align}\nabla_{\theta}(\theta^TX^TX\theta)&=\left(\nabla_{\theta^T}(\theta^TX^TX\theta)\right)^T\nonumber\\&=\left(\nabla_{\theta^TX^T}(\theta^TX^TX\theta)\nabla_{\theta^T}(\theta^TX^T)\right)^T\nonumber\\&=\left((\theta^TX^T+\theta^TX^T)X\right)^T\nonumber\\&=\left(\theta^TX^TX+\theta^TX^TX\right)^T\nonumber\\&=X^TX\theta+X^TX\theta\nonumber\end{align}$$
  • tr(θTXTy) = tr(yTXθ)
  • ∇θtr(θTXTy) = (∇θT(θTXTy))T((XTy)T)T = XTy

Set the derivative to 0, we have

XTXθ = XTy

which is called the normal equation.

From the normal equation, we can easily get the value of θ

θ = (XTX)−1XTy
