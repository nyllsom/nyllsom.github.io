However, convexity is a rare property for functions. In practical applications, the loss function is a high-dimensional function. In high-dimensional spaces, the stationary points of a randomly selected function are almost always saddle points, which do not prevent continued gradient descent. Moreover, if you believe that deep learning can extract meaningful patterns, the distance between local optima and the global optimum should not be excessively large.

The gradient descent shown above is _batch gradient descent_, where we think for all the training data and calculate the sum. This can be quite time-and-resouces-consuming. We need an alternative algorithm. That is _stochastic gradient descent_, where we update the parameters according to the gradient of error with respect to that single training example only. Although stochastic gradient descent may oscillate around the minumum of , in practice the result will be reasonably good approximations to the true minumum (simply by reducing the learning rate over time) and is oftern preferred over batch gradient descent particularly when the training set is large.
